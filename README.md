# Group-Messaging-App-
A basic group chatting app.

How to Use:

Open the PythonServer.py file first using the terminal.

Secondly, open the PythonClient1.py file two or more
times (number of times you open it will be the number
of clients connected to the server) using the terminal.

Note: This app is still a work in progress so
unfortunately there are still some glitches
regarding usernames. I'm doing my best to 
resolve those issues.
